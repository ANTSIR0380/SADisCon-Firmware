# SADisCon — хранилище прошивок

Официальные бинарные прошивки контроллеров SADisCon. Готовые образы распространяются через [GitHub Releases](https://github.com/ANTSIR0380/SADisCon-Firmware/releases), а не через файлы в ветке `main`.

## Компоненты системы

| Для пользователя | Аппаратная платформа | Способ обновления | Имя файла |
|---|---|---|---|
| **Базовое ПО** | ESP32-P4 | OTA по HTTPS | `SADisCon.bin` |
| **Модуль Wi-Fi** | ESP32-C6 | OTA через ESP32-P4 / ESP-Hosted | `network_adapter.bin` |
| **Контроллер нагрева** | STM32G070RB | **ST-Link / SWD** | `STM32G070.bin` |

**Важно:** OTA для STM32G070 отключено. Его образ сохранён только для архивирования и восстановления через ST-Link. Не используйте в рабочей системе ранее испытанные функции `FWBOOT`, `Extended Erase` и OTA STM32.

## Правила для следующих релизов

- **ESP32-P4:** сохранить существующую схему тегов `vMAJOR.MINOR.PATCH` (например, `v0.1.3`) и имя `SADisCon.bin`. Это важно для совместимости с уже действующей проверкой обновлений P4.
- **ESP32-C6:** тег `c6-vX.Y.Z` для стабильных версий; суффикс `-test.N` для испытаний, например `c6-v2.13.0-test.2`. Имя asset — `network_adapter.bin`.
- **STM32G070:** тег `stm32-vX.Y.Z` для будущих архивных сборок; имя asset — `STM32G070.bin`. Не считать наличие файла разрешением для OTA.
- Тестовые выпуски отмечать в GitHub как **Pre-release**. Стабильные — как обычные releases.
- Для каждого выпуска указывать: целевой контроллер, версию, изменения, известные ограничения, размер бинарного образа и SHA-256, инструкцию установки и восстановления.
- Не смешивать образы разных микроконтроллеров в одном релизе; не удалять и не переименовывать уже опубликованные теги, используемые устройствами.

## Совместимость автообновления

Репозиторий содержит **несколько независимых линеек прошивок**. Общий GitHub endpoint `/releases/latest` не подходит для автоматического определения последней версии конкретного контроллера без фильтрации тегов и проверки состава файлов. До внедрения фильтрации сохраняйте действующую структуру тегов P4 и используйте для C6 точные ссылки на assets.

## Безопасность и резервные копии

- Перед установкой прошивки проверяйте SHA-256 загруженного образа.
- Для ESP32-C6 сохраняйте полную резервную копию заводской Flash.
- Для STM32G070 сохраняйте работоспособный `.bin`, доступ к ST-Link/SWD и, при необходимости, полный дамп Flash.
- Рабочие выходы и процессы должны быть приведены в безопасное состояние согласно проектным ограничениям перед любой прошивкой управляющего оборудования.
